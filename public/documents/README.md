# PDF documents

Put your PDF files here (subfolders are supported). Run `npm run build` and redeploy.
The dropdown is generated automatically from actual PDF files, including file size.
Use readable filenames such as `Kalendari i garave 2026.pdf`.
Optionally add a title, category, and source URL in `data/document-details.json`.
The existing 2025 file is a real archived regulation, not a current 2026 regulation.
Remove it if you do not need the archive.
